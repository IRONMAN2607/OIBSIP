# OIBSIP_DataScience_task1 - Iris Flower Classification

This repository contains Oasis Infobyte Data Science Task 1.

## Objective
Build a machine learning model that classifies iris flowers into species using flower measurements.

## Steps Performed
1. Loaded and explored the Iris dataset.
2. Visualized feature relationships and class distribution.
3. Trained classification models.
4. Evaluated model performance using accuracy and classification metrics.

## Tools Used
- Python 3.11+
- Jupyter Notebook
- pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Outcome
A trained classification workflow that predicts iris species from sepal and petal measurements.

## How to Run
Clone this task repository and move into it:

```bash
git clone <your-task-1-repository-url>
cd OIBSIP_DataScience_task1
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start Jupyter from this repository root:

```bash
jupyter notebook
```

Open `notebook/task_1_iris_flower_classification.ipynb` and run all cells in order.
