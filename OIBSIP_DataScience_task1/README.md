# OIBSIP Data Science Task 1 - Iris Flower Classification

## Objective
Build a machine learning model that classifies iris flowers into species using flower measurements.

## Steps Performed
1. Loaded and explored the Iris dataset.
2. Visualized feature relationships and class distribution.
3. Trained classification models.
4. Evaluated model performance using accuracy and classification metrics.

## Tools Used
- Python
- Jupyter Notebook
- pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn

## Outcome
A trained classification workflow that predicts iris species from sepal and petal measurements.

## Project Files
- `notebook/task_1_iris_flower_classification.ipynb` - source notebook
- `outputs/task_1_executed.ipynb` - executed notebook with results

## How to Run
1. Install dependencies from the repository root:
   ```bash
   pip install -r ../requirements.txt
   ```
2. Open the notebook in Jupyter.
3. Run all cells in order.
